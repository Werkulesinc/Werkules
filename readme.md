# Werkules
### Personal AI Assistant Platform — by Werkules Inc

A real-time voice AI that can hear, see, understand, and control your computer. Supporting Windows, macOS, and Linux. Local execution. Zero subscriptions. Engineered for total autonomy.

---

## Overview

Werkules is a personal AI assistant platform powered by **Jarvis** — a voice-first AI that bridges the gap between your operating system and human intent. Through natural dialogue, Jarvis analyzes your screen, processes uploaded documents, executes complex workflows, and controls your computer with a responsive, adaptive interface.

It's not just an assistant — it's an extension of your digital life.

---

## Capabilities

### Core Features
| Feature | Description |
|---|---|
| Real-time Voice | Ultra-low latency conversation in any language |
| System Control | Launch apps, manage files, execute terminal commands |
| Autonomous Tasks | High-level planning for complex, multi-step goals |
| Visual Awareness | Real-time screen processing and webcam vision |
| Persistent Memory | Deeply remembers your projects, preferences, and personal context |
| Hybrid Input | Seamlessly switch between keyboard typing and voice commands |
| File Processing | Drop PDFs, source code, images, or documents for instant analysis |

## Quick Start

```bash
git clone <your-repo-url>
cd <project-folder>
pip install -r requirements.txt
playwright install
python main.py
```

> **Note:** If you encounter a `ModuleNotFoundError`, install the missing package via `pip install <module_name>`.
